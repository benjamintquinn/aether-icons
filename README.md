# Using the icons

## Format

All the icons were drawn with a 2 px stroke width on a 32x32 px grid and are intended for use in vector format. Should you choose to rasterize them, they'll look best with dimensions that are multiples of 16 (@2x) or 32 (@3x).
## Variants

Most icons are available in both line and filled variants, and those which combine both styles are considered filled. Filled and line variants can be combined to indicate colors, amounts, or a selected state.
## Badges

Some icons have variants which can be combined with "badges" to modify their meaning. Upper badges are for statuses (passive modifications), while bottom are for actions (active modifications). Using icons with the suffix `-BadgeStatus` or `-BadgeAction` will lead to the best results with badges, because they have cutouts that prevent an icon's lines appearing through the badge.
